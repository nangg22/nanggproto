## ✨ Fitur Unggulan

- 🎨 **Desain Glassmorphism Modern** — UI berbasis One UI Samsung dengan efek blur dan gradien elegan
- 🌗 **Dark / Light Mode** — Pergantian tema yang mulus dengan penyimpanan preferensi pengguna
- 🖥️ **Terminal Interaktif (NanggOS)** — Konsol simulasi dengan perintah seperti `help`, `about`, `skills`, `neofetch`, dan `silat`
- 🃏 **Efek 3D Tilt Card** — Kartu proyek yang responsif terhadap gerakan kursor
- 📊 **Floating Telemetry Panel** — Panel melayang real-time yang menampilkan CPU/RAM simulasi dan log aktivitas
- 📱 **Fully Responsive** — Tampil optimal di desktop, tablet, dan smartphone
- ⚡ **Performa Tinggi** — Lazy loading gambar dan animasi CSS yang dioptimalkan
- 📧 **Form Kontak Asli** — Terintegrasi dengan Formspree untuk pengiriman email sungguhan
